서비스 약관

시행일: 2026년 10월 18일

1. 서비스

word-log는 운영자 본인이 설교 영상을 만들어 자신의 유튜브 채널에 올리는 데 쓰는 개인용 도구이며, 다른 사용자에게 제공되는 서비스가 아닙니다.

2. YouTube 약관

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다.

3. 콘텐츠

업로드되는 영상과 자막의 내용에 대한 책임은 운영자에게 있습니다. 성경 본문은 대한성서공회 개역개정판에서 인용하고 출처를 밝힙니다.

4. 보증의 부인

도구는 있는 그대로 제공되며, 업로드 실패나 지연에 대해 보증하지 않습니다.
