개인정보처리방침

시행일: 2026년 10월 18일

word-log(이하 "도구")는 운영자 본인이 자신의 유튜브 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다.

1. 수집하는 정보

도구는 다른 사용자의 개인정보를 수집하지 않습니다. 운영자가 Google 계정으로 승인하면 유튜브 업로드 권한(youtube.upload)에 대한 인증 토큰만 발급받습니다.

2. 이용 목적

인증 토큰은 운영자가 확인하고 승인한 영상을 운영자 본인의 채널에 업로드하는 데에만 쓰입니다. 시청 기록, 구독자 정보 등 다른 데이터는 읽지 않습니다.

3. 보관과 보호

토큰은 GitHub 저장소의 암호화된 Secrets에만 보관되며 코드나 로그에 남지 않습니다. 운영자는 언제든 Google 계정 권한 페이지에서 접근을 철회할 수 있습니다.

4. 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 업로드된 영상에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
