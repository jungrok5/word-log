개인정보처리방침

시행일: 2026년 10월 24일

word-log(이하 "도구")는 운영자 본인이 자신의 유튜브 채널(@word-log)에 영상을 올리고 관리하기 위해 쓰는 개인용 도구입니다. 도구는 같은 운영자의 내부 도구 "one-scroll-bible tools"(one-scroll-bible.com)와 같은 Google API 클라이언트를 씁니다.

1. 수집하는 정보

도구는 다른 사용자의 개인정보를 수집하지 않습니다. 운영자가 Google 계정으로 승인하면 운영자 채널의 영상 업로드·설명·댓글·자막 관리 권한(youtube.force-ssl)과 채널 통계 조회 권한(yt-analytics.readonly)에 대한 인증 토큰만 발급받습니다.

2. 이용 목적

인증 토큰은 운영자가 확인하고 승인한 영상을 운영자 본인의 채널에 올리고, 그 영상의 조회수·시청 비율을 확인해 다음 영상을 개선하는 데에만 쓰입니다. 읽은 통계는 저장하지 않고 운영자가 요약해 기록하며, 시청자 개인의 정보나 구독자 목록은 읽지 않습니다.

3. 보관과 보호

토큰은 운영자 컴퓨터와 운영자 작업 환경의 환경 변수에만 보관되며 코드나 로그에 남지 않습니다. 운영자는 언제든 Google 계정 권한 페이지에서 접근을 철회할 수 있습니다.

4. 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 업로드된 영상에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
