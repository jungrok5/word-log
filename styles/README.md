# House styles

Styles proven on real word-log films, packaged so a new film starts from a kit instead of a blank canvas.
Each folder: `kit.js` (the style's materials and rendering, any story), `STYLE.md` (look, meanings it carries, API,
pitfalls, performance), `template.html` + `script.example.js` (a minimal new scene), and a worked example film.

`templates.jpg` — every 2026-10 kit's template at 15 s (the same seed story in each look), for picking at a glance.

## Start a film from a style
```
python3 tools/new-film.py sermons/<YYYY-MM-DD>-<본문> --style charcoal --id seed
```
1. Write `scenes/script.js` (beats, lines, cuts) from the storyboard; the end card comes from `source.json` and the loop seam
   is on by default (see CLAUDE.md 영상 전략). The first four kits' templates still fade in from black and hold a 4-s end card — retime them; the 2026-10 kits
   already start on the picture with the ~4-s end card and loop seam. Kits with characters carry a body rig (IK arms, hands at the
   grip, kneel/turn/hold helpers) — use it rather than drawing arms by hand, then run `tools/body-check.py`.
2. In `scenes/<id>-<slug>.html` replace the template's placeholder subject with the film's one image, using the kit.
3. Sound → `tools/cut-audio.py` → `tools/check-film.py --frames` → `tools/preview.py` → push → preview link; `tools/upload-meta.py`. MP4 only when asked.

`_shared/` holds what every film vendors: `lib.js` (canvas-film harness, phone-safe sizing) and `story.js`
(captions + end card). A film copies its kit and shared files, so improving a kit later never changes an old film.
Add a new house style when a film's style works: same four files, a row above.

## Upstream copy
The same kits live in the canvas-film skill: github.com/jungrok5/motion-skills → `canvas-film/kits/` (with
`scripts/from-kit.py` for any project). These copies here stay as they are; when a kit is improved or a new one is
added, update both (copy, never delete).
