# 메시지 점검 — 콘티를 보여 주기 전에 스스로 답한다

그림이 "멋있다"와 "내 이야기다"는 다르다. 문틈 1차(2026-10-18)는 무섭게는 보였지만 메시지가 반만 전달됐다:
문이 저절로 열려 "나"가 없었고, 비유 셋(문·누룩·유월절)이 섞였고, 반전(문설주의 피)은 교회 밖 사람에게 읽히지 않았다.
2차는 아래로 고쳤다. 콘티마다 이 표를 채워 storyboard.md에 넣는다.

| # | 질문 | 아니면 |
|---|---|---|
| 1 | **보는 사람이 화면 안에 있나?** (나·내 손·내 방·내 선택 — 1인칭 시점이나 "나"인 인물) | 저절로 일어나는 일은 남의 이야기다. 행동의 주체를 화면에 넣는다 |
| 2 | **박자마다 누가 행동하나?** (나 / 죄 / 하나님) 특히 반전의 주체가 그림으로 분명한가 | 모호하면 "누가 닫았지?"가 남는다. 손·빛·방향으로 보여 준다 |
| 3 | **비유가 하나인가?** 그림과 화면의 구절이 같은 은유인가 | 다른 은유의 구절은 설명란으로 뺀다 |
| 4 | **화면의 성경 구절 ≤ 2개**, 그림과 직접 맞물리는 것만 | 30초에 셋은 읽기 벅차다 (check-film이 경고) |
| 5 | **교회 밖 사람 테스트**: 성경을 모르는 사람이 반전을 그림만으로 이해하나 | 상징(유월절 피 등)은 그림이 스스로 말하게 하거나 자막·구절이 바로 붙게 한다 |
| 6 | **그림만 테스트**: 소리 끄고 자막을 가려도 흐름(처음 → 커짐 → 결정적 순간 → 반전)이 읽히나 | 자막이 이야기를 끌고 가면 설명 영상이다. 그림을 고친다 |
| 7 | **감정 곡선**: 박자마다 보는 사람이 느낄 한 단어 (예: 호기심 → 불안 → 공포 → 깨달음 → 안도) | 그 감정을 만드는 그림·소리가 없는 박자는 지운다 |
| 8 | **기억할 한 줄**: 절정에 내 말로 된 한 문장이 있나 (예: "열어 준 건 나였다") — 구절과 별개 | 구절만으로는 "아는 말"로 지나간다 |
| 9 | **수위**: 전 연령, 고어 없음, 악은 암시(그림자·손)로 | 자극은 메시지를 가린다 |
| 10 | **해석 테스트**: 처음 보는 사람이 "이게 무슨 말이지? 뭘 말하려는 거지?" 하는 순간이 한 번도 없나 | 해석이 필요하면 끝이다. 압축·상징·생략을 풀고 그림을 더 직접적으로 |
| 11 | **궁금증 사슬**: 박자마다 "그래서 어떻게 되는데?"가 생기고 다음 박자가 그걸 받아 주나 | 궁금증이 끊기는 박자에서 넘긴다. 순서를 바꾸거나 그 박자를 지운다 |
| 12 | **마지막 장면 ≈ 첫 장면**인가 (반복 재생) | 엔딩 그림을 첫 그림으로 돌아오게 한다 |
