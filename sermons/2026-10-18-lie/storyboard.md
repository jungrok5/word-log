# 콘티 — "아빠 없다고 해" (설교: 고전 5:1-8 「절대로 괜찮다고 넘기면 안 되는 것」)

상태: **컨펌(목탄) → 제작** · 세로 1080×1920 · 본편 28.5초 (엔딩 26.0–28.5)
LEARNINGS.md에서 가져온 것: 0초부터 그림 / 화면 속에 행동하는 "나" / 비유 하나·구절 ≤ 2·절정에 기억할 한 줄 / 본편 하나만

## 한 장면
**내가 "괜찮겠지" 하고 넘긴 작은 거짓말 하나가, 나를 보는 아이에게 그대로 옮는다.**
→ 같은 자리, 같은 전화, 같은 손짓이 세대를 건너 되풀이된다. (출처: 설교 [0:42:34] 아빠의 거짓말 예화)

## 콘티 (본편 약 29초)
| 시간 | 화면 | 자막 | 소리 |
|---|---|---|---|
| 0–3 | 0초부터: 일요일 아침 거실 탁자, 울리는 휴대폰. **내 손**(아빠)이 휴대폰을 아이 쪽으로 밀어 준다 | 아빠 없다고 해 | 진동, 시계 초침 |
| 3–8 | 아이가 휴대폰을 받아 들고 나를 올려다본다 → 전화에 대고 | 아빠… 없어요 | 작은 목소리 대신 자막, 낮은 피아노 한 음 |
| 8–12 | 아이의 눈이 잠깐 머문다. 탁자 위 아이 손에 작은 얼룩(거짓말)이 번진다 | 아, 이래도 되는구나 | 피아노 두 번째 음 |
| 12–17 | **같은 자리, 몇 년 뒤**: 그림이 지워지고 다시 그려지며 아이가 10대가 된다(벽시계가 돌고 창가 화분이 자란다). 이번엔 10대가 휴대폰을 **내 쪽으로** 밀어 보낸다 — 붉은 자국이 나에게 돌아온다 | 나 없다고 해 | 같은 진동, 미는 소리 |
| 17–20 | 그 모습을 본 나(아빠)의 손이 멈춘다 — 얼룩은 내 손에서 시작됐다 | 그 말, 어디서 배웠을까 | 소리가 줄어듦(무음은 아님) |
| 20–24 | **다시 몇 년 뒤**: 어른이 된 아이가 자기 아이에게 휴대폰을 민다. 얼룩이 종이 전체로 번진다 | 적은 누룩이 온 덩어리에 / 퍼지는 것을 알지 못하느냐 — 고린도전서 5:6 (개역개정) | 진동이 겹쳐 울림 |
| 24–26.5 | **처음 그 아침으로 돌아온다**. 휴대폰이 울리고, 이번엔 **내 손이 직접 받는다** — 얼룩이 걷힌다 | 여보세요, 접니다 | 진동이 멈춤, 따뜻한 화음 |
| 26.5–29 | 엔딩 카드(자동): 2026.10.18 주일 1부예배 / 절대로 괜찮다고 넘기면 안 되는 것 / 고린도전서 5:1-8 / 더라이프지구촌교회 · 김인환 담임목사 → 첫 장면(울리는 휴대폰)으로 이어짐 | | 잔향 |

- 성경 구절 1개(고전 5:6, 개역개정 그대로). "아빠 없다고 해 / 아, 이래도 되는구나 / 그 말, 어디서 배웠을까 / 여보세요, 접니다"는 설교 예화를 바탕으로 쓴 대사·자막(설교자 직접 인용 아님).
- 설교자의 말 후보(영상에서 확인 후에만): [0:52:13] "난 괜찮아, 난 괜찮아… 괜찮지 않다고요!" — 넣는다면 24초 전환 직전.

## 스타일 (하우스 스타일에서)
| | 스타일 | 이 장면에서 | 이유 |
|---|---|---|---|
| **추천** | **고딕 목탄 (charcoal)** — 밝은 낮 톤으로 | 같은 종이 위에서 지우개로 지우고 다시 그리며 아이가 자란다(켄트리지식 변신). **지워도 남는 숯 자국**이 거짓말의 흔적으로 남고 번진다 | 시간이 흐르는 걸 "한 장면 안에서" 보여 주는 이 매체 고유의 동작 = 이번 메시지(대물림) 그 자체. 문틈(호퍼)과 확실히 다른 그림 |
| 대안 1 | 그림자극 (puppet) | 같은 인형 무대에서 아빠·아이·손자 인형이 같은 손짓을 되풀이 | 우화처럼 단순하고 얼굴을 그리지 않아도 됨 |
| 대안 2 | 솔 바스 그래픽 (bass) | "없다고 해"가 오린 종이 띠로 세 번 되풀이되며 점점 커짐 | 가장 빠르고 강렬, 숏츠형 |
| 대안 3 | 호퍼풍 (hopper) | 같은 거실을 고정 카메라로, 빛만 세월 따라 바뀜 | 사실적이지만 문틈 2차와 너무 비슷해 보일 수 있음 |

## 메시지 점검 (tools/MESSAGE-CHECK.md)
| # | 답 |
|---|---|
| 1 화면 속의 나 | 아빠인 "내 손"이 처음에 휴대폰을 밀고, 마지막에 직접 받는다 |
| 2 행위자 · 반전의 주체 | 거짓말을 시키는 건 나 → 배우는 건 아이 → 되풀이하는 건 아이의 아이 → 끊는 것도 나(내 손이 직접 받음) |
| 3 비유 하나 | 옮아가는 것(얼룩·누룩). 그림의 얼룩과 구절의 누룩이 같은 "번짐" |
| 4 화면 구절 | 1개: 고전 5:6 |
| 5 교회 밖 사람 | 성경을 몰라도 "아이가 아빠를 따라 한다"는 누구나 안다 |
| 6 그림만 | 휴대폰을 미는 손 → 아이가 같은 손짓 → 그 아이의 아이도 → 내 손이 받는다 |
| 7 감정 곡선 | 익숙함("다들 그러지") → 찜찜함 → 뜨끔함 → 두려움 → 결단 |
| 8 기억할 한 줄 | 그 말, 어디서 배웠을까 |
| 9 수위 | 일상 장면, 자극 없음 |
| 10 해석 테스트 | 대사가 일상어라 설명 없이 바로 읽힘. 세월이 흐르는 건 같은 자리에서 아이가 자라는 그림으로 |
| 11 궁금증 사슬 | 아이가 거짓말할까? → 했다 → 그래서? → 아이도 똑같이 → 그 다음 세대도? → 멈출 수 있나? → 내가 받는다 |
| 12 처음 = 끝 | 울리는 휴대폰과 내 손 — 마지막엔 받고, 다시 재생되면 처음처럼 울린다 |

## 제작 메모
- 붉은색(한 가지 색) = 거짓말. 미는 손가락 끝에서 시작해 휴대폰이 지나간 자리에 번지고, 세 번째 세대에서 탁자 전체로 퍼진다. 마지막에 지우개가 걷어 낸다.
- 컨펌 뒤 바꾼 것: 12–17초 10대가 친구가 아니라 **나에게** 휴대폰을 민다(새 인물 없이, 몸짓이 나에게 되돌아오는 그림이 더 강함).
