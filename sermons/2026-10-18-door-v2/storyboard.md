## 한 장면
**작은 타협은 내가 조금씩 여는 문이다. 결국 내가 닫을 수 없게 되고, 그리스도의 희생만이 그 문을 닫는다.**
→ 1인칭 시점: 내 손이 핑계마다 문을 한 뼘씩 열고, 건너편의 손에게 문을 빼앗긴다. (출처: 설교의 C.S. 루이스 예화)

## 메시지 점검 (tools/MESSAGE-CHECK.md)
| # | 답 |
|---|---|
| 1 화면 속의 나 | 1인칭 손. 처음부터 끝까지 내 손이 문에 있다 |
| 2 행위자 · 반전의 주체 | 여는 건 나 → 빼앗는 건 죄 → 닫는 건 내 손이 아님(피가 칠해진 뒤 문이 스스로 닫힘) |
| 3 비유 하나 | 문. 누룩 구절(5:6)은 설명란으로 |
| 4 화면 구절 | 2개: 창 4:7(문에 엎드린 죄), 고전 5:7(유월절 양) |
| 5 교회 밖 사람 | 붉은 획이 칠해지자 그림자가 물러나고 문이 닫힌다 — 의미를 몰라도 "저것이 막았다"는 읽힘. 구절이 바로 붙음 |
| 6 그림만 | 손이 연다 → 다른 손이 잡는다 → 내 손이 놓는다 → 문이 빼앗긴다 → 붉은색 → 닫힌다 |
| 7 감정 곡선 | 망설임 → 합리화 → 불안 → 공포·무력감 → 깨달음 → 안도 |
| 8 기억할 한 줄 | 열어 준 건 나였다 |
| 9 수위 | 악은 그림자와 손가락만, 피는 문설주에 칠한 붓 획 |
| 10 해석 테스트 | 성경을 몰라도: 내가 문을 열었다 → 빼앗겼다 → 무언가가 막아 줬다 |
| 11 궁금증 사슬 | 열까? → 뭐가 있지? → 저 손은? → 문을 뺏기면? → 저 빨간 건? → 닫혔다 |
| 12 처음 = 끝 | 닫힌 문 + 문틈의 빛 + 문 위의 내 손 |
